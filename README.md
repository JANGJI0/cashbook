# 📋 cashbook 게시판
가계부 웹 미니 프로젝트 입니다. 

사용자는 로그인하여 수입/지출 카테고리를 작성하고, 해당 요일에 수입/지출내역, 메모를 입력하여 작성합니다. 또한 자신의 소비활동을 보기위해 전체, 년도별, 월별, 특정년도 월별 수입/지출 통계를 확인 할 수 있습니다.
# ⏱ 개발 기간
+ 2025.04.10 (목) ~ 2025.04.16(수)
+ 가계부 구조 이해
+ 쿼리 구조 이해
+ UI 스케치 작성

# 💻 개발 환경
+ Version : Java 21
+ IDE : Eclipse

# ⚙️ 기술 스택
+ JSP & JSTL
+ MySQL
+ CSS
+ Bootstrap 5
+ JavaScript

# 🔍 SQL ERD

# ✨주요기능
+ 로그인/로그아웃
+ 수입/지출에 대한 카테고리 추가/삭제
  + 수입/지출 이모지표현
+ 수입/지출 내역 추가/수정/삭제
+ 영수증 이미지 첨부/수정/삭제
+ 달력리스트 구성
  + 로그인 상태창이랑 같이 보이게 구성
  + 금액입력, 영수증 첨부하면 달력에 표현
+ 사용자 수입/지출에 대한 통계
    + 전체/년도별/월별/특정년도 월별 통계 구현
    + 그래프로 알기쉽게 UI 구현
